# Timeline of Jainism

A responsive, single-page heritage website for exploring Jain history, Tirthankaras, textual traditions, Acharyas, leaders, Jinalayas and research articles.

## Preview locally
Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript; no build tools or dependencies are required.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The Pages panel will show the exact live URL.

## Current prototype features
- Responsive navigation and mobile menu
- Timeline search and category filters
- 24 Tirthankara profile cards
- Sections for Agamas, Acharyas, Jain rulers/freedom fighters and blogs
- State-based Jinalaya directory prototype
- Research sources and editorial caveats

## Before public launch
- Replace the placeholder contact email in `index.html` with an email address you control.
- Verify temple names, addresses and all profile details with authoritative sources.
- Expand the Jinalaya sample records; they are clearly marked as starter records and are not a complete directory.
- Review dates carefully. Distinguish Jain traditional chronology from modern historical dating.
- Add your own licensed images and official social links when ready.
